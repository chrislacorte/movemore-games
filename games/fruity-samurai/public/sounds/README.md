# Sound files

Replace files here and update paths in `src/constants/gameConfig.js` → `AUDIO_URLS`.

| File | Used for |
|------|----------|
| `sword-swoosh-sheet.wav` | Swipes & fruit slices (segment playback) |
| `explosion.wav` | Bomb hit |
| Add `game-over.wav` | Game over (wire in `AUDIO_URLS.gameOver`) |

Volumes & timing: `src/constants/audioConfig.js`
